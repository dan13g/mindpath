## Source table coverage

- **CLIENTS** → HUB_CLIENT + SAT_CLIENT_DETAILS
- **ORGANISATIONS** → HUB_ORGANISATION + SAT_ORGANISATION_DETAILS
- **SERVICES** → HUB_SERVICE + SAT_SERVICE_DETAILS
- **CONTRACTS** → HUB_CONTRACT + SAT_CONTRACT_DETAILS + LNK_CONTRACT_ORGANISATION
- **CONTRACT_SERVICES** → LNK_CONTRACT_SERVICE + SAT_CONTRACT_SERVICE_DETAILS (Link Satellite)
- **REFERRALS** → HUB_REFERRAL + SAT_REFERRAL_DETAILS + client/organisation/contract Links
- **ASSESSMENTS** → HUB_ASSESSMENT + SAT_ASSESSMENT_DETAILS + referral/client Links
- **TREATMENT_PLANS** → HUB_TREATMENT_PLAN + SAT_TREATMENT_PLAN_DETAILS + referral/assessment/service Links
- **AUTHORISATIONS** → HUB_AUTHORISATION + SAT_AUTHORISATION_DETAILS + referral/contract Links
- **CLINICIANS** → HUB_CLINICIAN + SAT_CLINICIAN_DETAILS
- **CLINICIAN_SPECIALISMS** → HUB_SPECIALISM + LNK_CLINICIAN_SPECIALISM; no satellite because the source row has no descriptive payload beyond the relationship itself
- **CLINICIAN_ALLOCATIONS** → HUB_ALLOCATION + SAT_ALLOCATION_DETAILS + referral/clinician Links
- **SESSIONS** → HUB_SESSION + SAT_SESSION_DETAILS + referral/client/clinician/service Links
- **OUTCOMES** → HUB_OUTCOME + SAT_OUTCOME_DETAILS + referral/client/session Links
- **INVOICES** → HUB_INVOICE + SAT_INVOICE_DETAILS + organisation/contract Links
- **INVOICE_LINES** → HUB_INVOICE_LINE + SAT_INVOICE_LINE_DETAILS + invoice/referral/session/service Links

### Important
A satellite is not created merely because a source table exists. Satellites hold descriptive/history-bearing attributes. A pure association such as `CLINICIAN_SPECIALISMS` can legitimately be represented by a Hub + Link without an empty satellite.
